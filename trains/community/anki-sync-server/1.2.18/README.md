# Anki Sync Server

[Anki Sync Server Enhanced](https://github.com/chrislongros/anki-sync-server-enhanced) is a self-hosted sync server for [Anki](https://apps.ankiweb.net/), the popular open-source spaced repetition flashcard application. Built from official Anki source with multi-user support, automated backups, and monitoring.
