# Snapshot Visualizer

[Snapshot Visualizer](https://github.com/synecho/truenas-snapshot-visualizer) shows the ZFS snapshots of your
TrueNAS system the way WinDirStat shows files: a cushion treemap by size, a timeline by age, per-dataset
statistics and a sortable snapshot table, so you can quickly see which snapshots and periodic tasks use your space.

<!-- x-readme:warnings:start -->

⚠️ **WARNING:** This app requires a TrueNAS API key, which gives it administrative control over the system.

Misconfiguration or a malicious update can compromise data integrity, security, or system stability. Install at your own risk.
