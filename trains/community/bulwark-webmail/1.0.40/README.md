# Bulwark Webmail

[Bulwark Webmail](https://bulwarkmail.org/) is a modern, self-hosted webmail suite built for Stalwart Mail Server, powered by the JMAP protocol. It provides webmail, calendar, contacts, and file access through a browser-based interface.
