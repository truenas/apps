# nexbrand

[nexbrand](https://www.nexbrand.de) keeps the corporate design of your clients in one place, on your own
server: colours, fonts, logos, a type scale, rules and example files per client and per project, with
every version kept. Contrast checks by WCAG 2.2, client reviews through a link, and every version as code,
over an API and MCP.
