# Blackbriar

[Blackbriar](https://github.com/DerAachener/blackbriar) is a companion app for shared Plex servers.
It reads the ratings of all users, shows which titles are safe to delete once everyone who requested them
has watched and rated them, and can remind users by email. Connections to Plex, Seerr, Radarr, Sonarr and
TMDB are set up in the web interface after the first start. The setup code for the first sign-in is printed
in the app logs.
