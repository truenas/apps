# Nametag

[Nametag](https://nametag.one) is a personal CRM for the people in your life. Keep notes,
birthdays and important dates, see how everyone is connected in a network graph, and get
reminders to stay in touch. Two-way CardDAV sync works with Google Contacts, iCloud,
Outlook and Nextcloud.

See the [self-hosting docs](https://docs.nametag.one/self-hosting/) for all configuration options.
