# nextrmnl

[nextrmnl](https://github.com/DerKezorm/nextrmnl) is SSH and SFTP in the browser for the machines in
your own network: a terminal with tabs and jump hosts, file transfer next to it, a vault per account
for keys and passwords that only the account's password opens, host keys that are checked and
remembered, accounts by invitation or OpenID Connect, an optional second factor and encrypted backups.
