# ActuallyFreeCD Server

[ActuallyFreeCD Server](https://github.com/D69wookie/ActuallyFreeCD-Server) - A free, server-based audio CD ripping
application with a web interface, FLAC/MP3 encoding, MusicBrainz and CD-Text metadata, AccurateRip verification,
and optical-drive control.
