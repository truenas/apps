# Arr Dashboard

[Arr Dashboard](https://github.com/Kha-kis/arr-dashboard) is a unified dashboard for managing multiple
Sonarr, Radarr, Prowlarr, Lidarr, Readarr, Plex, Tautulli, Jellyfin, Emby, and Seerr instances.
