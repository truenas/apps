# nexsift

[nexsift](https://github.com/DerKezorm/nexsift) is the filter for your homelab's notifications. Services
report to nexsift instead of to your phone, through doors that answer like a Gotify server, an ntfy
server, a Discord webhook, a mail server or a syslog server. nexsift collects everything in one inbox,
bundles the routine, closes problems on their all-clear and passes on only what matters.
