# Money

[Money](https://github.com/Muffy0906/firefly-money) is a modern, mobile-friendly frontend for
[Firefly III](https://www.firefly-iii.org/). It needs a running Firefly III server and a Personal
Access Token from it.

**!!! WARNING !!!**

• Host Networking
