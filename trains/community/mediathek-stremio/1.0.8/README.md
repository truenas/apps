# Mediathek

[Mediathek](https://github.com/tuschla/mediathekview-2-stremio) is a Stremio add-on for the on-demand libraries
(Mediatheken) of German public broadcasters such as ARD, ZDF and ARTE, served live from the MediathekViewWeb API.
