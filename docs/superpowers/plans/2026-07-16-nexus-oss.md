# Nexus Repository 3 (sonatype/nexus3) TrueNAS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new `nexus` community app packaging Sonatype Nexus Repository 3 (`sonatype/nexus3:3.94.0`) to the TrueNAS apps catalog, realising truenas/apps#4502 with the current (non-EOL) image.

**Architecture:** Single `nexus` container (image `sonatype/nexus3`) plus a conditional `permissions` init container (`ixsystems/container-utils`). Nexus OSS uses an embedded OrientDB in `/nexus-data` — no external DB. UID/GID hardcoded to 200 (image-mandated). HTTP-only in this phase (HTTPS deferred to a follow-up PR). Docker registry connectors exposed via a user-configurable `docker_ports` list. JVM heap configurable via `nexus.java_heap`; raw JVM flags via `nexus.additional_java_opts`.

**Tech Stack:** TrueNAS ix-dev catalog (Docker Compose rendered from Jinja2 templates + YAML schema), rendering library `2.3.8`, Python 3.11 (devbox), `ghcr.io/truenas/apps_validation` for local render/validation.

## Global Constraints

- App directory: `ix-dev/community/nexus/` — `name: nexus` MUST match the directory.
- `train: community` must match the parent directory.
- Rendering library: `lib_version: 2.3.8`, `lib_version_hash: cd75c897a1e8fef54b5bd00d0d8849f240bc50db2ef650eccc0ee74f3b2b2dc1` (from `library/hashes.yaml`).
- Image: `sonatype/nexus3` tag `3.94.0` (NOT `sonatype/nexus` which is EOL Nexus 2). `container_utils_image: ixsystems/container-utils:1.0.2`.
- Hardcoded run_as UID/GID 200 (the image's `nexus` user). Do NOT expose `run_as` as a user question — precedent: `jenkins`, `cloudbeaver`.
- `web_port.port_number` default MUST be unique catalog-wide (enforced by `.github/scripts/port_validation.py`). Use **30451** (next available as of 2026-07-16; re-run `port_validation.py` before commit to confirm it is still free — if taken, pick the next from the script's "Next 5 available ports" output and update both `questions.yaml` and this plan).
- `docker_ports` list items: `port_number` and `container_port` are `int`, `required: true`, **no default** (so `port_validation.py` does not count them as catalog port slots — `item_looks_like_port` skips fields without a default). Precedent: `eclipse-mosquitto` `additional_ports`.
- Healthcheck target port is the **container** port 8081 (`values.consts.web_container_port`), NOT the host port. The image listens on 8081 fixed.
- No `app_migrations.yaml` / `migrations/` in this phase — new app, version `1.0.0`.
- Surgical changes only. Do not touch any other app or shared files except `catalog.json` is auto-regenerated by CI (do not edit by hand).
- Commits: one logical commit per task. Do NOT push (user pushes manually after review). Branch from `master`; work on a feature branch `add-nexus` (see Task 1).

## File Structure

```
ix-dev/community/nexus/
├── app.yaml                          # Metadata: name, version, run_as_context, lib_version, icon, sources
├── item.yaml                         # Catalog display: categories, icon_url, screenshots, tags
├── ix_values.yaml                    # Static defaults: images, consts (container names, UID/GID, paths, notes)
├── questions.yaml                    # User config schema: 5 groups (Nexus/Network/Storage/Labels/Resources)
├── README.md                         # One-line description
├── templates/
│   ├── docker-compose.yaml           # Jinja2 template (the only template file)
│   └── test_values/
│       └── basic-values.yaml         # CI test config (non-default ports, host_path storage)
```

No `macros/` directory in Phase 1 (HTTPS macro deferred to Phase 2). No `migrations/`, `app_migrations.yaml`, `deprecations.yaml`, `to_keep_versions.yaml`.

**Responsibility boundaries:**
- `app.yaml` / `item.yaml` — catalog metadata only, no runtime logic.
- `ix_values.yaml` — static image refs + `consts` consumed by the template (single source of truth for container names, UID/GID, ports, notes body).
- `questions.yaml` — the user-facing schema; every value the template reads from `values.*` must be defined here.
- `templates/docker-compose.yaml` — the only rendering logic; reads `values.*` and `values.consts.*`; produces the compose JSON.
- `templates/test_values/basic-values.yaml` — exercises non-default paths (host≠container port mapping, a `docker_ports` entry, non-default heap).

**Files:**
- Create: `ix-dev/community/nexus/templates/docker-compose.yaml`

**Interfaces:**
- Consumes: all `values.*` produced by Task 2 and all `values.consts.*` produced by Task 1.
- Produces: rendered Docker Compose JSON (validated in Task 5).


Then create `ix-dev/community/nexus/templates/docker-compose.yaml`:

```jinja2
{% set tpl = ix_lib.base.render.Render(values) %}
{% set c1 = tpl.add_container(values.consts.nexus_container_name, "image") %}

{% set vm_params = namespace(items=[]) %}
{% do vm_params.items.extend([
  "-Xms%dM"|format(values.nexus.java_heap),
  "-Xmx%dM"|format(values.nexus.java_heap),
  "-XX:MaxDirectMemorySize=%dM"|format(values.nexus.java_heap),
]) %}
{% for opt in values.nexus.additional_java_opts %}
  {% if opt.startswith("-Xms") or opt.startswith("-Xmx") or "-XX:MaxDirectMemorySize" in opt %}
    {% do tpl.funcs.fail(
      "Expected [nexus.additional_java_opts] to not contain reserved heap options "
      "[-Xms/-Xmx/-XX:MaxDirectMemorySize]. Set heap via [nexus.java_heap]."
    ) %}
  {% endif %}
  {% do vm_params.items.append(opt) %}
{% endfor %}

{% set perm_container = tpl.deps.perms(values.consts.perms_container_name) %}
{% set perm_config = {"uid": values.consts.run_as_user, "gid": values.consts.run_as_group, "mode": "check"} %}

{% do c1.set_user(values.consts.run_as_user, values.consts.run_as_group) %}
{% do c1.environment.add_env("INSTALL4J_ADD_VM_PARAMS", vm_params.items|join(" ")) %}
{% do c1.environment.add_user_envs(values.nexus.additional_envs) %}

{% do c1.healthcheck.set_test("curl", {"port": values.consts.web_container_port, "path": "/service/rest/v1/status"}) %}
{% do c1.healthcheck.set_start_period(120) %}
{% do c1.healthcheck.set_interval(30) %}
{% do c1.healthcheck.set_timeout(10) %}
{% do c1.healthcheck.set_retries(5) %}

{% do c1.add_port(values.network.web_port, {"container_port": values.consts.web_container_port}) %}

{% for dp in values.network.docker_ports %}
  {% do c1.add_port(dp) %}
{% endfor %}

{% do c1.add_storage(values.consts.nexus_data_path, values.storage.nexus_data) %}
{% do perm_container.add_or_skip_action(values.consts.nexus_data_path, values.storage.nexus_data, perm_config) %}

{% for store in values.storage.additional_storage %}
  {% do c1.add_storage(store.mount_path, store) %}
  {% do perm_container.add_or_skip_action(store.mount_path, store, perm_config) %}
{% endfor %}

{% if perm_container.has_actions() %}
  {% do perm_container.activate() %}
  {% do c1.depends.add_dependency(values.consts.perms_container_name, "service_completed_successfully") %}
{% endif %}

{% do tpl.portals.add(values.network.web_port) %}
{% do tpl.notes.set_body(values.consts.notes_body) %}

{{ tpl.render() | tojson }}
```
