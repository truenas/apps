# Nexview

[Nexview](https://github.com/DerKezorm/nexview) is a media discovery dashboard for a household. It
shows new releases from TMDB, marks what is already in your library, and hands requests to Radarr
and Sonarr, with accounts, approvals, quotas and a per-user age restriction.
