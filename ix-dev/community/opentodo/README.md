# OpenTodo

[OpenTodo](https://open-todo.app) is a self-hosted, local-first task manager with offline sync across devices.

The first visitor creates the owner account; after that, the owner invites people.
Installing the app, offline use, push notifications, passkeys and end-to-end encryption need https:
put OpenTodo behind a reverse proxy with a certificate and set **Base URL** to that address.
