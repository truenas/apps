# Scanvento

[Scanvento](https://scanvento.com) is an IT asset management and discovery platform: network discovery and agents,
hardware and software inventory, licences, contracts, vulnerabilities and the asset lifecycle in one web application.

Scanvento is proprietary software, not open source. Without a licence file it runs as the free edition
(every module except MSP, one tenant, up to 250 active assets, no expiry); larger installations need a licence.
