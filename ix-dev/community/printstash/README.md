# PrintStash

[PrintStash](https://printstash.org) is an open-source, self-hosted library for 3D
printing: it brings files from your computer, model marketplaces and NAS into one
place, previews them, opens them in your slicer, and keeps print settings and
results with each model. It also lists and monitors your printers.

Deployment and configuration documentation lives at
[printstash.org/docs](https://printstash.org/docs).
