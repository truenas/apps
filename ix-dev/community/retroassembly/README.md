# RetroAssembly

[RetroAssembly](https://retroassembly.com) is a self-hosted retro game collection cabinet that lets you organize your ROM library and play classic games directly in your web browser.

Run RetroAssembly on TrueNAS with persistent storage for your game library, ROMs, and save states.

For documentation and supported gaming platforms, see the [RetroAssembly GitHub repository](https://github.com/arianrhodsandlot/retroassembly).
