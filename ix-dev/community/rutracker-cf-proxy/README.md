# RuTracker CF Proxy

[RuTracker CF Proxy](https://github.com/rofl3228/rutracker-cf-proxy) lets Prowlarr use Cloudflare-protected
RuTracker: the Cloudflare clearance cookie comes from Byparr, and requests are sent with a matching browser
fingerprint. It ships a Prowlarr indexer definition that can be installed automatically.
