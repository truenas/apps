# MediaMan

[MediaMan](https://github.com/MJWaters1985/MediaMan) organizes, imports and transcodes a Jellyfin media
library: it names files the way Jellyfin expects, brings in finished downloads from any download client,
and shrinks files while keeping their resolution, HDR, Dolby Vision, every audio track and every subtitle.
