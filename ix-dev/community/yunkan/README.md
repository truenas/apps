# SkyView

[SkyView](https://yun-kan.com/) is a self-hosted NVR for RTSP and ONVIF IP cameras with
on-device AI detection. Video stays on the local network; no vendor cloud is involved.

**!!! WARNING !!!**

• Host Networking

• mDNS Announcements
