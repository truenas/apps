# HexOS

Everything you love, on a server you own. [HexOS](https://hexos.com) is a force multiplier
for the TrueNAS you already run, not a replacement: install it here, claim the server
at deck.hexos.com, and get the Command Deck on top of the pools, shares, users and
apps you have today. Over a hundred curated apps and VMs that install in one tap,
HexOS Anywhere to reach every app from anywhere with your network closed, Buddy
Backup to a friend's server, the Hardware Advisor watching your exact parts, and
notifications a human can read. The full TrueNAS UI stays put.

This app is the installer: it marks the server as a HexOS system and serves a single "Claim this server" page.
After you claim the server at deck.hexos.com with its TrueNAS admin password, HexOS replaces this app
with its own HexOS app and keeps the app's data. If the server already runs HexOS, the app removes itself.
