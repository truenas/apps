# HexOS

[HexOS](https://hexos.com) adds the HexOS Command Deck on top of the TrueNAS you already run:
one-tap apps and VMs, remote access through HexOS Anywhere, Buddy Backup and hardware health monitoring.
Your pools, shares, users, apps and the TrueNAS UI stay as they are.
