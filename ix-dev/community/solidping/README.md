# SolidPing

[SolidPing](https://www.solidping.io) is a self-hosted uptime monitor: HTTP, TCP, UDP, ICMP, DNS, SSL, SMTP,
SSH, database and browser checks, alerts, status pages and on-call, in a single Go binary on SQLite.
