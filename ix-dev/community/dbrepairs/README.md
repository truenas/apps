# DBRepairs

DBRepairs is a free and open-source repair shop manager designed for repair workshops and service centres.

## Features

- Customer management
- Repair intake and tracking
- Repair status history
- A4 repair sheets
- PDF export
- Multi-language interface
- Shared PostgreSQL server edition
- Automatic database backups
- Portable `.dbrepairs` backups
- Browser-based access

## Web interface

After installation, open the DBRepairs WebUI from the TrueNAS Apps page.
