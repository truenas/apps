# Kinopeer

[Kinopeer](https://github.com/kinopeer/kinopeer) is a qBittorrent web UI built around movies and TV series. Find a title, pick a release found by Prowlarr, send it to qBittorrent and manage the downloads, on a phone or a computer. It connects to the qBittorrent and Prowlarr apps and asks for their addresses on its first start.
