# CineDock

[CineDock](https://github.com/cinedock/unraid-templates) gives Plex, Emby or Jellyfin an enhanced browsing experience on the NVIDIA Shield TV, on an Amazon Fire TV Stick, or in a browser on your computer or tablet. It does not scan, copy or change media files.

After installation, open the CineDock web portal and follow its plain-English setup wizard to connect the media server you already run. A TMDB API key is optional and adds actor biographies, filmographies and improved spotlight selection.
