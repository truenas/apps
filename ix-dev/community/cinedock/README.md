# CineDock

[CineDock](https://github.com/cinedock/cinedock) gives an existing Emby, Jellyfin or Plex server a polished interface for televisions, phones and browsers. It does not scan, copy or change media files.

After installation, open the CineDock web portal and follow its plain-English setup wizard to connect the media server you already run. A TMDB API key is optional and adds actor biographies, filmographies and improved spotlight selection.
