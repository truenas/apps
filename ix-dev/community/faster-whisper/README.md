# Faster Whisper

[Faster Whisper](https://github.com/SYSTRAN/faster-whisper) is a fast implementation of OpenAI's Whisper model, built on CTranslate2.
This app runs the [Wyoming Faster Whisper](https://github.com/OHF-Voice/wyoming-faster-whisper) speech-to-text server,
which can be added to Home Assistant through the Wyoming integration.
