# Plex Repairman

[Plex Repairman](https://github.com/chrisstoll1/plex-repair-discord-bot) is a Discord assistant for diagnosing and repairing Plex, Sonarr and Radarr media issues, with optional Seerr requests. Repairs follow configurable confirmation and Discord role policies.

Requires a Discord bot and OpenAI Codex authentication. Optional form sign-in can be enabled under Settings > Security. See the [setup and backup instructions](https://github.com/chrisstoll1/plex-repair-discord-bot#first-time-setup).
