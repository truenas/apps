# 百智办公 (Baizhi Office)

[百智办公](https://work.baizhi.cloud/)是面向团队的开源 AI 办公工作台，支持办公、编程与设计任务，以及模型、知识库、技能、专家、MCP 连接器和规则的共享管理。

本应用部署团队服务器，不会在 NAS 主机上运行桌面 Agent。生产环境请使用 HTTPS 反向代理；模型和外部工具调用可能将内容发送到相应服务。免费与付费功能以官网说明为准。

源码采用 AGPL-3.0。配置、备份和升级要求请参阅[上游部署文档](https://github.com/chaitin/MonkeyCode/blob/main/monkeyai/README.md)与[产品文档](https://work.docs.baizhi.cloud/)。
