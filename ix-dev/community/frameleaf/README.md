# Frameleaf

**Your photos. Your server. Everywhere.** Bring photos and videos together on hardware you control. Browse a timeline, organise albums and folders, find people and places, edit photos, and share selected memories with family. Optional local machine learning adds smart search and recognition. The self-hosted library needs no Frameleaf Cloud account; optional Cloud services are separate.

**Included in this app:** the Frameleaf server and web app, a dedicated PostgreSQL 19 database, and optional machine learning with a persistent model cache. This package was generated from the signed **frameleaf-v1.2.1** release; application images follow the latest published version.

**Before you install:** choose separate persistent locations for media and the database, set a database password, and review the [TrueNAS installation guide](https://frameleaf.app/docs/nas/truenas/). Use a fresh Frameleaf database. Changing an image does not convert an existing PostgreSQL cluster. Back up the database and original photos and videos before updates. Allow additional memory and processing time for machine learning on larger libraries.

**After installation:** open the app's Web Portal, create your administrator and follow the [first steps](https://frameleaf.app/docs/start/first-steps/). This catalogue app runs the application directly. For guided installation and service management instead, see [Frameleaf Manager](https://frameleaf.app/docs/start/install/).
