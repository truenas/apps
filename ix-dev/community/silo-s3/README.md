# Silo S3

[Silo](https://silo.pgsty.com/) is a community-maintained fork of the open-source MinIO server, published by PGSTY.
It is an S3-compatible object storage server with the full web console, and it reads existing MinIO data directories,
MINIO_* environment variables and mc clients unchanged.
