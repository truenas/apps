# Corvus

[Corvus](https://corvus-gateway.github.io/corvus/) is a self-hosted reverse proxy and web application firewall
with a web console: proxy hosts with Let's Encrypt certificates, redirections, TCP/UDP streams,
attack-pattern blocking, automatic bans, security rules, a browser challenge, an access queue (waiting room)
and a live traffic monitor.

On first start, open the admin console (HTTPS, self-signed certificate), enter the one-time setup token
from the app logs (the line with setup_token) and create the administrator account.
