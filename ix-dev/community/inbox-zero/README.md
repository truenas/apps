# Inbox Zero

[Inbox Zero](https://www.getinboxzero.com) is an open-source AI email assistant that organizes
your inbox, pre-drafts replies in your tone, and automates email management for Gmail and Outlook.

See the [self-hosting documentation](https://docs.getinboxzero.com/hosting/self-hosting) for
details on required Google/Microsoft OAuth credentials and LLM provider setup.
