# NeoGuard

[NeoGuard](https://github.com/Daddelgreis74/neoguard) is a 100% local AI camera guard for RTSP and ONVIF IP cameras (including TP-Link Tapo and Thingino devices).

**Key Features:** Multi-camera monitoring with live JPEG/HLS/MJPEG/WebRTC streaming, local YOLOv8n person detection and auto-tracking, YuNet and SFace face recognition, 48-hour unknown person logging, ONVIF PTZ control with presets, privacy mode toggle, and a multilingual Web UI (English and German).

**Configuration:** Set your initial login credentials in the app wizard and configure cameras, detection zones, schedules, and known faces directly in the NeoGuard Web UI. All configuration, face embeddings, and event logs are stored persistently in the configured data directory.
