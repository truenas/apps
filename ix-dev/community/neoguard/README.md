# NeoGuard

[NeoGuard](https://github.com/Daddelgreis74/neoguard) is a 100% local multi-camera AI security, person tracking, face recognition, and 48-hour unknown person logging application for RTSP and ONVIF IP cameras.

## Features
- Multi-camera management with 2-column grid view and brand presets (TP-Link Tapo, Reolink, Hikvision, Dahua, Imou, Thingino, Custom RTSP/ONVIF)
- Local YOLOv8n + OpenCV YuNet + SFace ONNX face recognition (no cloud required)
- Known persons marked as OK; unknown persons logged with camera badges and snapshots for 48 hours
- ONVIF PTZ control, auto-tracking (`0.3x–5.0x`), customizable presets 1–3, and multilingual Web UI (`DE`, `EN`, `FR`, `ES`)
