# nexcanvas

[nexcanvas](https://github.com/DerKezorm/nexcanvas) is a whiteboard for your own server, in the spirit of
Apple Freeform: sticky notes, shapes, text, lines, pen and highlighter, photos and PDFs on an endless
board, edited live by several people at once. Frames and scenes, a shape library, templates, export as
PNG and PDF, and JSON Canvas to exchange boards with other apps. Project site: https://www.nexcanvas.de

The first account becomes the operator and needs the setup code from the container logs, a new one at
every start until nexcanvas is set up. To choose it yourself, add `NEXCANVAS_SETUP_TOKEN` under
Additional Environment Variables.
