# Wondarr

[Wondarr](https://github.com/wulfftech/wondarr) is an \*arr for single songs. It finds each song you want on Soulseek (slskd is bundled), YouTube Music, torrents and usenet, checks it is the right recording, tags it and files it into your music library.

The Soulseek source needs a Soulseek account. See the [documentation](https://wulfftech.github.io/wondarr/).
