# PhotoStructure

[PhotoStructure](https://photostructure.com) is a self-hosted photo and video
library. It imports from the folders you mount, deduplicates, and organizes
everything by date, location, camera, directory hierarchies, and other metadata.

The web interface currently has no login: anyone who can reach the web port can browse
the library. Keep it on your LAN, or put it behind a reverse proxy that handles
authentication.

Volumes, environment variables, and troubleshooting are documented in
[PhotoStructure for Docker](https://photostructure.com/server/photostructure-for-docker/).
