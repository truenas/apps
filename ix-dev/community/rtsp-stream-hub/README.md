# RTSP Stream Hub

[RTSP Stream Hub](https://github.com/Daddelgreis74/rtsp-stream-hub) is a lightweight, standalone web application for managing, ONVIF discovery, and on-the-fly transcoding of RTSP camera streams into browser-compatible MJPEG.
