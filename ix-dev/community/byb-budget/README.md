# BYB! Budget

BYB! Budget is a private, self-hosted household envelope budgeting app. It stores
money as integer cents, supports multiple household users, recurring entries,
bank-statement import, reports, targets, backups, and optimistic save-conflict
protection.

The persistent `/data` directory contains `budget.json`, `passwords.json`, and
`sessions.json`. Back up the first two as a matched pair before changing an
existing installation.
