# Pellu Home Server

[Pellu Home Server](https://pellu.co/home-server/linux) shares the videos (and their subtitles) in the folders you choose with the Pellu apps on your phones, tablets and TV at home. Files play as they are: nothing is transcoded, and nothing is uploaded.

After installing, open the Web UI and enter the setup code from the app's logs (a line like "enter the setup code ABCD-EFGH"), then choose a password, pick your folders from /media and link the server to your free Pellu account.

Mount your media read-only under /media as Additional Storage. Host Network lets the Pellu apps find the server by themselves (Bonjour).
