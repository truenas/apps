# NasWarden

[NasWarden](https://github.com/ahmd-soliman/naswarden) is a real-time monitoring dashboard for TrueNAS SCALE:
ZFS pool and dataset health, disks, VMs, alerts and replication in one glanceable page,
plus a Prometheus /metrics endpoint.

**!!! WARNING !!!**

This application requires additional elevated permissions beyond standard containerization protections. Use at your own risk.

The following additional privileges may be enabled from installing this application:

• Host Networking

• TrueNAS API Key
