# OmniRoute

[OmniRoute](https://omniroute.online) is a free MIT AI gateway — one endpoint for 340+ providers (90+ free) and 1200+ models including Claude, GPT, Gemini, Kimi, DeepSeek and more. Features quota-aware auto-fallback, RTK + Caveman token compression (15-95% savings), MCP/A2A support, and unified OpenAI-compatible API.
