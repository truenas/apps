# UniHub

[UniHub](https://github.com/mrksrus/selfhost-unihub) combines mail, contacts, calendars, tasks, notes and recordings in a self-hosted web app.

An external HTTPS reverse proxy is required. See the [installation guide](https://github.com/mrksrus/selfhost-unihub/blob/v0.23.0/docs/INSTALLATION.md) for setup and encryption-key rotation.

Private noncommercial use is free. See the [licensing terms](https://github.com/mrksrus/selfhost-unihub/blob/v0.23.0/LICENSING.md) for commercial use.
