# Kasm Workspaces

[Kasm Workspaces](https://www.kasmweb.com) is a docker container streaming platform for delivering
browser-based access to desktops, applications, and web services.

**!!! WARNING !!!**

This application requires additional elevated permissions beyond standard containerization protections. Use at your own risk.

The following additional privileges may be enabled from installing this application:

• Host Networking

• Privileged Mode
