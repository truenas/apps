# OpenHabitTracker

[OpenHabitTracker](https://openhabittracker.net) - take notes, plan tasks, track habits.
Free, ad-free, open source, no account required.
This container is the self-hosted sync server: native apps for Windows, Linux, Android, iOS and macOS log into it and sync.
