# Clumoove

Clumoove is a self-hosted cloud data migration and synchronization platform for files, calendars, and contacts.

## Features

- Transfer and synchronize data between providers (Nextcloud, Google Drive, Dropbox, OneDrive, HiDrive, S3, WebDAV, SMB, SFTP, FTP, Immich, Seafile, Koofr, MEGA, and local storage).
- Zero-disk streaming transfers directly through memory.
- Automated cron-based synchronization schedules and multi-threaded background migrations.
- 3-way hash integrity verification and conflict resolution strategies (skip, overwrite, rename).
- Integrated cloud file manager with file previews and thumbnail generation.
- Multi-channel notification delivery (Gotify, ntfy, Telegram, Discord, Email).
- Security with AES-256-GCM encrypted credentials, TOTP 2FA, and audit logging.

## Default Port

- Web UI: `8380`
