# TRAWL

[TRAWL](https://trawl.germondai.com/) is a self-hosted web scraping engine that
bypasses JS challenges and captchas (Cloudflare, Turnstile, reCAPTCHA, hCaptcha,
GeeTest). It is a FlareSolverr and Byparr drop-in replacement for your \*arr stack.
