# nexbeat

[nexbeat](https://github.com/DerKezorm/nexbeat) finds music and requests it from Lidarr. It
recommends artists from what the library already holds, browses genres, searches MusicBrainz, and
adds a requested album or a whole artist to Lidarr, with accounts, invitations and quotas.
