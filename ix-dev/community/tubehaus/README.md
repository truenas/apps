# TubeHaus

[TubeHaus](https://github.com/biolend83/tubehaus) is your own YouTube for the household: no ads, no tracking and
no Google account. Every phone, computer and TV in the house sees the same library (subscriptions, history,
playlists, resume points), in the browser or in the TubeHaus apps. It talks to YouTube itself (TubeHaus' own engine), so it is just two containers: the TubeHaus server and its web app.
