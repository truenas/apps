# ComfyUI

[ComfyUI](https://github.com/Comfy-Org/ComfyUI) - The most powerful and modular
Stable Diffusion GUI, API and backend with a graph/nodes interface.

This app uses the community-maintained `chinabanker/comfyui-official` image
(built from the official Comfy-Org source with PyTorch 2.11.0+cu128, rebuilt
daily via GitHub Actions). Requires an NVIDIA GPU and a host driver supporting
CUDA 12.8 (TrueNAS SCALE 25.10 or newer).
