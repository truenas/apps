# ComfyUI

[ComfyUI](https://github.com/Comfy-Org/ComfyUI) - The most powerful and modular
Stable Diffusion GUI, API and backend with a graph/nodes interface.

This app uses the community-maintained `chinabanker/comfyui-official` image
(built from the official Comfy-Org source with PyTorch 2.13.0+cu130 (CUDA 13.0),
rebuilt via GitHub Actions when upstream changes). Requires an NVIDIA GPU and a
host driver supporting CUDA 13.0 (TrueNAS SCALE 26 with bundled driver 590.x,
or any Linux host with a CUDA 13.0-capable driver). Supports RTX 30/40/50 series.
