# arrVantage

[arrVantage](https://github.com/Kazwahs/arrvantage) is a unified web dashboard for your media automation stack - Radarr, Sonarr, Lidarr, Prowlarr, Plex/Jellyfin/Emby, qBittorrent/SABnzbd, Overseerr/Jellyseerr, and Tdarr, all in one place instead of a separate browser tab for each.
