# Filestash

[Filestash](https://github.com/mickael-kerjean/filestash) - a file manager / web client

Filestash is a file manager / web client for SFTP, S3, FTP, WebDAV, Git, Minio, LDAP, CalDAV, CardDAV, Mysql, Backblaze, ...
