# ihasmail

[ihasmail](https://ihasmail.org) is immutable webmail for [Stalwart Mail Server](https://stalw.art): mail, calendars, contacts, files and filters in one app, talking only JMAP. It needs a Stalwart 0.16 or newer that it can reach, and keeps nothing of its own beyond an optional session file.
