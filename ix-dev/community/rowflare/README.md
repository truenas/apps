# Rowflare

[Rowflare](https://rowflare.com) is an open-source Airtable alternative: grid, kanban, calendar, timeline, gallery and form views, Airtable-compatible formulas, automations, a REST API and an MCP server. Each base is its own SQLite database, and everything is stored in one data directory.

The first account created becomes the owner of the instance; after that, people join by invite.
